# Coding API helpers

Use paid API helpers only for implementation, testing and code review. Send self-contained,
sanitized source snippets; never send secrets, mail contents or private user context.
Invoke `aiwb-subtask spawn --resource <id> --task-type code` on the owning device.
These helpers return proposed code; the leading agent reviews it, applies it and runs tests.
Record every implementation, review and rework in the candidate cost ledger. A failed call or
zero balance is not a completed coding task. Never choose a winner before comparable accepted tasks.
