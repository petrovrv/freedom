## Employer module (confidential)

- Everything read through the employer's tools (mail, calendar, team chats, document sites, the employer portal, HR) and
  every answer of the employer's models is confidential: keep it in this environment. Never copy it into shared chats,
  family chats, other members' environments, public sites or the tool library.
- Writing for the employer goes through the employer's model gateway tool when the task asks for it; say so when the
  gateway is unavailable instead of silently writing the text yourself.
- Mail and calendar tools only prepare drafts and proposals: never send, accept or delete without the owner's explicit yes.
